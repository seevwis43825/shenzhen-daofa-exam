# 深圳道法训练：题型、版式与质检

## 默认训练结构

当用户没有指定学校结构时，可使用：50 分钟、50 分，填空 5 分、单项选择 20 分、材料题 25 分。它是便于九上单元训练的默认结构，不应标称为官方真题原卷。用户的题量、分值或考试时长要求优先。

强化覆盖版可使用填空 10 分、单选 30 分、两道材料题 20 分，共 60 分、60 分钟；题号连续，且两份或多份试卷之间应减少重复考点。

## 卷头与版式

- 自编训练卷头：`九年级上册《道德与法治》单元训练（自编）`，再写年级册次、单元和训练范围。
- 说明写明开卷训练、考试时间、总分、作答位置；没有答题卡时不写考生号、条形码或“交回答题卡”。
- 正文仿宋或宋体约 11 pt；标题黑体；全卷纯黑；A4 页面；页脚标页码。
- 填空题的多空题标明每空分值；材料题留作答位置；表格跨页时重复表头。
- 选择题题干、漫画、选项不可拆散；材料题小问与至少两行作答区尽量同页。

## 选择题配置建议

每套十题中，优先确保不同认知任务都有出现：

| 类型 | 命题要点 |
|---|---|
| 情境判断 | 由材料行为回扣教材，不直接复述新闻结论。 |
| 漫画寓意 | 画面证据、教材概念、最有针对性的措施。 |
| 排序／时间轴 | 用明确时间锚点，避免靠学生年龄推算。 |
| 观点辨析 | 围绕绝对化、越权、偷换概念设置干扰。 |
| 组合选择 | 每项可独立判断，正确组合不机械重复。 |
| 图表／文化 | 材料的数据、古语或图示必须足以支持判断。 |

深圳本土材料应以公共服务、社区治理、科技创新、绿色发展、区域协同等可公开验证场景为主。不能把“公民参与”说成“直接行使国家权力”，不能把个案问题扩大为对制度的否定。

## 材料题评分

- 体现类：每点写“教材观点 1 分＋材料证据 1 分”。
- 原因／意义类：分开列角度，避免“促进发展”换词重复。
- 措施类：写主体、行动和目标；没有具体行动的口号不应给满分。
- 评析类：分别评合理性、问题、正确做法；只写“错误”不给理由分。
- 青少年题：理想认同、学习本领、日常实践、社会参与中选择与题目相符的方向。

## 交付质检

- [ ] 教材标题、术语与用户给定教材一致。
- [ ] 所有时政日期、主体、法律或数据已在官方来源核验。
- [ ] 分值合计、题号、答案表和评分标准一致。
- [ ] 学生版无答案；答案版每题有答案和必要解析。
- [ ] 自编卷不伪称官方真题，不含无对应答题卡的条形码说明。
- [ ] Word/PDF 渲染后无彩色标题、跨页题干、图片裁切、空白答案页或字体异常。
