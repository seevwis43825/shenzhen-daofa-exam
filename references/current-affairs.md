# 时政专题：来源、更新与九上示例

## 使用原则

1. 优先使用全国人大、国务院、中央政府部门、新华社、深圳市政府等原始发布。
2. 写明事件日期和资料更新时间；新闻事实与教材结论分开表达。
3. 只选能稳定映射到本册知识点的时政。不要用未核实的地方排名、比例、网络评价或预测数据。
4. 每学期检查一次。过期的数字、活动名称和政策进度应删改；稳定的教材链接可以保留。

## 时政专题卡模板

每张卡按四项写：

1. **时政摘要**：一至两句，写清主体、时间、行动。
2. **教材链接**：写课题与 3—5 个关键词。
3. **常见考法**：指出可能的选择题、材料题或辨析题设问。
4. **答题关键词**：给能直接落笔的教材表述，不用新闻口号替代。

时政材料题采用“教材观点＋材料证据＋作用或结论”。对措施题，用“主体＋具体行动＋目标”；对辨析题，用“合理处＋问题＋正确方向”。
